# Expert ROI submission folder

This folder deliberately has **no actual human-traced ROI files yet**.

Only ImageJ/Fiji ROI ZIP archives created by an expert from the original 100x BMP images should be stored here.

Required filename: S02_F1.zip (two-digit working S index and field number). The identifier must match the original BMP folder processing condition. For 4 wt.% images, do not use the old TIFF numbering; consult Phase 1 Task 1 provenance.

Never upload synthetic ROI files, screenshots pretending to be ROI shapes, or threshold-derived automated contours as human ground truth.

Manual image review decisions and unresolved conditions should be preserved in the original 19-field template.

The automated comparison workflow will report PENDING while this folder contains no ROI ZIPs.
